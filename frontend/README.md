# Tadic Management frontend

ReactJS + TypeScript + Vite starter for the internal management system.

```powershell
cd frontend
npm install
npm run dev
```

The week-one page previews the shared app layout, status display, and a local search interaction. It uses static setup information; it does not read or write Odoo data. Business screens and the Odoo API contract will be defined after the P.KHKD and Ban quản trị discovery work. Visual tokens and design decisions are documented in `../DESIGN.md`.
