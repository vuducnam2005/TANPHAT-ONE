# Tadic Management frontend

ReactJS + TypeScript + Vite starter for the internal management system.

```powershell
cd frontend
npm install
npm run dev
```

The current page is a month-one visual prototype for the shared app layout, status display, and a local search interaction. It uses static setup information; it does not read or write Odoo data. Keep it as a reference while month one focuses on discovery, system architecture, and techstack selection. Business screens and the Odoo API contract must be defined and approved before product development begins. Visual tokens and design decisions are documented in `../DESIGN.md`.
